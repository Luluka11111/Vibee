# Moods — Digital Heart & Mood Diary

Moods — это веб-приложение для отслеживания ежедневного настроения, выполненное в стиле ретро-операционной системы. Проект позволяет пользователям вести визуальный дневник, добавляя стикеры настроения на календарную сетку и оставляя текстовые заметки.

---

## Основной функционал

*   **Авторизация и безопасность**: Система регистрации и входа в систему с использованием JWT-токенов.
*   **Интерактивный календарь**: Просмотр дней текущего месяца с возможностью переключения между месяцами.
*   **Трекер настроения**: Выбор одного из 8 уникальных стикеров для каждого дня.
*   **Персонализация**: Приветственный экран с динамическим отображением имени пользователя.
*   **SPA Навигация**: Использование React Router v6 для переключения между страницами (/, /auth, /app) и обработка ошибок 404.
*   **Ретро-дизайн**: Интерфейс, стилизованный под старый монитор с пиксельными элементами и анимациями.

---

## Технологический стек

### Frontend
*   **React.js (Vite)** — библиотека для создания интерфейса.
*   **React Router** — декларативная маршрутизация.
*   **Axios** — взаимодействие с API.
*   **Lucide-React** — набор иконок.
*   **Date-fns** — работа с датами и календарем.

### Backend
*   **Node.js & Express** — серверная часть.
*   **MongoDB** — база данных для хранения пользователей и записей.
*   **JSON Web Tokens (JWT)** — аутентификация пользователей.
